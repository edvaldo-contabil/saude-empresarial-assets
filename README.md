# Saúde Empresarial — recursos visuais

Logotipos PNG de 720 × 720 pixels, convertidos dos SVGs originais. A assinatura usa texto HTML e exibe o logotipo com 190 × 190 pixels.

## Spark Mail

1. Abra `assinaturas/assinatura-edvaldo.html` e copie todo o código.
2. Nas configurações de assinatura do Spark, abra o editor HTML, substitua o conteúdo e salve.
3. Envie um e-mail de teste para outra conta e confirme o logotipo, a legibilidade e os links.

A imagem é carregada por HTTPS usando raw.githubusercontent.com. Alguns destinatários precisam autorizar imagens externas. Não renomeie nem remova o PNG enquanto a assinatura estiver em uso.

## GitHub Pages (opcional)

Em Settings → Pages, selecione Deploy from a branch, branch main, pasta / (root), Save. Depois da publicação, a imagem estará em https://edvaldo-contabil.github.io/saude-empresarial-assets/assinaturas/logo-saude-branco.png . A assinatura atual funciona sem essa configuração.
